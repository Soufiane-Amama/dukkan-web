# دُكّان: النسخة الكاملة

واجهة متجر «دُكّان» من مسار الواجهات، موصولة بخادم «دُكّان» الحقيقي (Express و MongoDB) من مسار الباك إند، ومعها ما يحتاجه متجر حقيقي:

- تصفّح المنتجات بالتصنيفات والصفحات، والبحث، وصفحة كل منتج.
- سلة محفوظة في المتصفح، وإتمام طلب يُحفظ في قاعدة البيانات، برسالة واضحة إن نفدت كمية منتج.
- **إنشاء حساب**، وتسجيل الدخول، وصفحة الحساب مع **طلباتي** وحالة كل طلب.
- **لوحة صاحب المتجر** (`/admin`): الأرقام والإيرادات والمخزون المنخفض، وإضافة التصنيفات والمنتجات وتعديلها وحذفها، وإدارة حالة الطلبات.
- كل تعديل في اللوحة يظهر في صفحات المتجر فوراً (`app/api/revalidate`).

## التشغيل

شغّل خادم «دُكّان» أولاً (انظر README الخادم)، ثم:

```bash
npm install
cp .env.example .env.local
npm run dev
```

ثم افتح http://localhost:3000.

| الحساب | اسم المستخدم | كلمة المرور |
|---|---|---|
| زبون تجريبي | `emilys` | `emilyspass` |
| صاحب المتجر | `owner` | قيمة `ADMIN_PASSWORD` في ملف `.env` للخادم |

## ما الجديد مقارنة بنسخة مسار الواجهات

| الملف | الإضافة |
|---|---|
| `lib/api.ts` | إنشاء الحساب، وطلباتي، ودوال اللوحة `admin`، وتحديث الكتالوج بعد التعديل |
| `lib/auth.tsx` | `register` بجانب `login` |
| `app/register` و `components/RegisterForm.tsx` | صفحة إنشاء الحساب، بخطأ تحت كل حقل كما يرسله الخادم |
| `components/MyOrders.tsx` | قائمة الطلبات في صفحة الحساب |
| `app/admin` و `components/admin/` | لوحة صاحب المتجر |
| `app/api/revalidate/route.ts` | يحدّث صفحات المتجر المحفوظة بعد التعديل، لصاحب المتجر فقط |
| `lib/images.ts` | صور النطاقات غير DummyJSON تُعرض دون محسّن الصور |

## أين الحماية؟

إخفاء اللوحة عن الزبائن في الواجهة لراحة الاستعمال فقط. الحماية الحقيقية في الخادم: كل مسار `/admin` فيه يرفض أي رمز ليس لصاحب المتجر، حتى لو أرسل أحدهم الطلب بنفسه دون الواجهة.
